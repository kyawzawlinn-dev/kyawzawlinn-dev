# Kyaw Zaw Linn

> Hi, I'm Kyaw — I build command-line tools and the web systems around them.

I'd rather ship something small that works than something big that impresses — clean code, sane defaults, and behavior you can predict. Most of what I ship lives under [**@jasonkyawlab**](https://github.com/jasonkyawlab).

## What I'm working on

| Project | What it does | Built with |
| :--- | :--- | :--- |
| [**lazyport**](https://github.com/kyawzawlinn-dev/lazyport) | Point it at a port; it tells you what's holding it — and whether killing it is safe. | C++ |
| [**LogReport**](https://github.com/kyawzawlinn-dev/LogReport) | Reads the last 24h of logs, pulls out what actually broke, and emails you the summary. | Python |
| [**Kibo**](https://github.com/kyawzawlinn-dev/Kibo) | A private health assistant that keeps your data on your own machine. | Go |

…plus a fair amount of full-stack product work (POS systems, auth, real-time dashboards) that lives in private org repos.
